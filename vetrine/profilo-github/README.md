### Ciao, sono Gaspare 👋

**Sviluppatore full-stack e automazioni AI per PMI**: lavoro da remoto (Europe/Rome).

Costruisco software che fa risparmiare tempo alle aziende: **agenti AI** (anche con LLM locali, senza mandare dati nel cloud), automazioni WhatsApp e agenti vocali, **CRM e gestionali su misura**, integrazioni tra i sistemi che l'azienda usa già.

**Stack:**
Python · FastAPI · Node.js · TypeScript · React · Next.js · PHP · MySQL · PostgreSQL · Docker · Linux · LLM e agenti AI · Ollama · React Native / Expo · Android / Kotlin
